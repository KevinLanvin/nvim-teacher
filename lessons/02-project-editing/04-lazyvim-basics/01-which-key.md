Welcome to Campaign 4: LazyVim Basics. This campaign covers the LazyVim-specific tools that make navigating a project fast — the key discovery system, the file explorer, fuzzy finding, project-wide search, and the quickfix list.

Press <leader> and wait without pressing anything else — a popup appears listing every keymap that starts with leader, grouped by category. That's which-key: a live map of what's available so you never have to remember every shortcut. Press a key to drill into its group, Esc to dismiss.

Try it: press <leader>, then wait for the popup, then press f to see the file group. You'll see ff, fr, fb and their descriptions. Press Esc to back out.

<leader>sk opens the full keymap list in the Snacks picker — searchable, so you can type any keyword to find a keymap you half-remember. New move unlocked.
