Press <leader><space> — the Snacks file picker opens, listing every file in the project. Start typing any part of a filename and the list filters instantly. New move unlocked: fuzzy finding matches characters in order but not necessarily consecutively, so "uscmp" finds "UserComponent.vue".

j and k navigate the results. Enter opens the selected file in the current window. <C-s> opens it in a horizontal split instead, <C-v> in a vertical split — same split shortcuts as <leader>- and <leader>| from the splits level, but without leaving the picker first.

<leader>fr opens the recent files picker instead of the full project list — files you've had open lately, newest first. Faster than fuzzy-finding the full tree when you know you were just there. New move unlocked.
